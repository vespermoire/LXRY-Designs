## Deployment

Hosted on Netlify. Deployed from GitHub.

### Deploy to Netlify

1. Connect GitHub repo to Netlify
2. Set build command: (none - static site)
3. Set publish directory: `/`
4. Domain: lxrydesigns.com (via Easily DNS)
